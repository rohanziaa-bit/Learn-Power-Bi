# Learn-Power-Bi
Power BI Learning Journey

This repository contains my Power BI practice work as I continue learning data analytics and data visualization.

I started exploring Power BI to understand how raw data can be turned into meaningful visuals and how different features can help make data easier to understand.

Rather than focusing only on creating charts, I've been trying different features and learning how they work through hands-on practice.

What I've Practiced

Here are some of the concepts I've explored so far:

Data Visualization: Working with different charts and understanding when to use each visual.

Bins and Lists: Exploring how to group numerical data into ranges.

Data Models: Practicing with different model-related concepts in Power BI.

Conditional Formatting: Using formatting rules to make important values stand out in tables.

Drill Down: Exploring how to move from summarized information to more detailed data.

Charts and Visuals: Practicing bar charts, column charts, line charts, donut charts, scatter charts, and combination charts.

Cards and Tables: Learning how to present important numbers and detailed information.
